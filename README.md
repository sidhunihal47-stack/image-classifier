# Image Classifier: Happy vs Sad

This project implements an image classification model that distinguishes between images of happy and sad people using deep learning with TensorFlow.

## Project Overview

In this project, we build a convolutional neural network (CNN) to classify images into two categories:

- **Class 0**: Happy people
- **Class 1**: Sad people

The model is trained on a dataset of images and is saved in the `models/` directory. The classifier can be used to predict whether a given image depicts a happy or sad person.
